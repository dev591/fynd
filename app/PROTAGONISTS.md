# Protagonist candidates (pick after the use case drops)
Needs: broken → fixed → working-product states, drivable by one progress value 0..1, cheap as SVG/canvas.

1. **Tangled parcels → sorted grid.** Scattered boxes drift randomly; the turn snaps them onto labeled lanes. Best for logistics/returns/fulfilment.
2. **Scattered catalog → clean grid.** Mismatched product cards (bad titles, wrong categories) align and get tagged. Best for catalog/listing quality.
3. **Noisy signal → resolved line.** Jittery demand/price line smooths into a forecast with confidence band. Best for forecasting/pricing.
4. **Fragmented cart → one checkout path.** Many dropped-off dots funnel into one path to a "paid" node. Best for conversion/abandonment.

Recommendation: 1 or 2 as a particle/SVG field (Dipole-Field "chaos to order" idea, rebuilt ourselves to avoid license risk). Same object shrinks into the login card in chapter 6.
